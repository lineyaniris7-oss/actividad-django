# Sistema de productos

Aplicación web desarrollada con Django para registrar, eliminar, editar, detallar y listar productos, y registrar, eliminar, editar, detallar y listar categorias, Taller 1 SENA.

## Tecnologías
- Python
- Django
- SQLite
- HTML
- Git y GitHub

## Ejecución
1. Crear el entorno virtual
2. Instalar Django: pip install django
3. Ejecutar migraciones: python manage.py migrate
4. Ejecutar servidor: python manage.py runserver

## Funcionalidades
- Registrar productos
- Listar productos
- Detalle productos
- Eliminar productos
- Editar productos
- Registrar categorias
- Listar categorias
- Detalle categorias
- Eliminar categorias
- Editar categorias
